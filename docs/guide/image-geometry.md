# Исходный прямоугольник изображения

**C-IMAGE-RECT-01.** Модель содержит общие данные и проверку;
разбор форматов, native units, bindings, rendering и нативная приёмка принадлежат
потребителю. Новых зависимостей нет.

## Координаты и хранение

`ImageSourceRect(left, top, right, bottom, *, extra={})` — неизменяемый DTO.
Исходные bounds изображения — `(0, 0, 1, 1)`, единицы — нормализованные доли
исходного размера по соответствующей оси. Координаты конечны, `right > left`
и `bottom > top`. Отрицательные значения, значения выше единицы и полностью
внешняя область допустимы. Bool, строки, NaN/Infinity и вырожденные/обратные
прямоугольники отклоняются с `ValueError` и адресом.

Прямоугольник определяет область source space, помещаемую в `Image.box`.
Внешние области не означают экстраполяцию pixels. Модель не выбирает fill,
масштабирование, clipping, alpha или алгоритм получения pixels. `Image.box`,
ссылка на ресурс и исходные bytes не меняются при записи прямоугольника.

Например, `(-0.13333, 0.26667, 0.86667, 0.86667)` описывает область с полем слева.
Это координаты углов, а не величины отступов справа/снизу.

Carrier — необязательное свойство `Image.properties['opendoc.image-source-rect']`:

```json
{
  "format": "opendoc.image-source-rect",
  "version": 1,
  "left": -0.13333,
  "top": 0.26667,
  "right": 0.86667,
  "bottom": 0.86667
}
```

Отсутствие carrier не добавляет ключей в прежние документы и не меняет
конструктор Image. JSON документа остаётся 2 с чтением 1/2. Прежний читатель
может сохранить carrier как неизвестное property, но не подтверждает его
семантику. Неизвестная версия известного format отклоняется; другое opaque
значение не интерпретируется и не перезаписывается setter.

## API и миграция

| API | Поведение |
| --- | --- |
| `ImageSourceRect.to_dict(*, limits=None)` | Независимые координаты и неизвестные поля через общий typed codec |
| `ImageSourceRect.from_dict(data, *, limits=None)` | Обязательны все четыре координаты; unknown JSON fields сохраняются в extra |
| `get_image_source_rect(image, *, limits=None)` | Независимая запись, либо преобразование прежнего ImageCrop, либо None |
| `set_image_source_rect(image, rectangle, *, limits=None)` | Атомарно записывает новый carrier и очищает Image.crop |
| `set_image_source_rect(image, None, *, limits=None)` | Удаляет carrier и Image.crop; остальные properties сохраняются |

ImageCrop сохраняет прежнее значение: неотрицательные доли, отрезанные с четырёх
краёв, с положительной оставшейся областью. Getter вычисляет только явное
соответствие `(crop.left, crop.top, 1-crop.right, 1-crop.bottom)`, не меняя crop
или JSON. Без обоих объявлений возвращается None; явный полный прямоугольник
отличается от отсутствия значения.

Оба представления вместе — конфликт, даже при численном совпадении. Полная
валидация и JSON отклоняют такой документ. Setter выполняет **явную миграцию**:
новая запись заменяет source viewport и снимает старый crop. Им можно явно
устранить конфликт; он не вычисляет новое значение по некорректному старому crop.

При замене сохраняется прежний extra, переданные ключи имеют приоритет.
Extra не может затенять координаты; при записи carrier также зарезервированы
поля format/version. Getter/codec/setter
возвращают или сохраняют независимые JSON-контейнеры; неудачная запись, в том
числе по лимиту, не меняет исходное изображение и его properties.

## Сохранность, бюджеты и актуальность

Все операции принимают `DocumentLimits`; размер/depth/nodes неизвестных полей
и всего carrier учитываются. Явный увеличенный бюджет передаётся через все
шаги без подмены стандартным. Превышение даёт прежний `ArtifactLimitError`
с path/quota/maximum. Полный документ дополнительно проверяет ресурсные ссылки
и общий embedded-бюджет. Источники ресурсов не открываются.

Clone/merge/extract и два JSON-цикла сохраняют DTO, unknown fields и ресурсные
карты. Изменение координат меняет объявление и JSON; потребитель может сравнить
независимые DTO либо полные `to_dict()` snapshots перед повторным использованием
своих image/layout bindings. Автоматической нативной freshness модель не
предоставляет: setter не подтверждает прежние измерения, экспорт или отрисовку.
Snapshots TextLayout относятся к тексту; unrelated text bindings не меняются.

Структурный счётчик `cropped_images` считает наличие ImageCrop либо известного
source rectangle. Эквивалентная миграция не выглядит потерей объявления.
Счётчик не сравнивает координаты и не измеряет pixels; content_hash изображения
по-прежнему описывает bytes ресурса, а не source viewport или рендер.

Исполняемый пример: [image_geometry.py](../../examples/image_geometry.py).
