# Внутренние ссылки и якоря

`Anchor(id)` обозначает начало одного вхождения элемента. Якорь можно установить на `Paragraph`, `Table`, `TextRun`, `Formula` или `Image`; `set_anchor(node, anchor)` устанавливает его, `get_anchor(node)` читает, а `set_anchor(node, None)` удаляет. Один элемент хранит один якорь. Это точка, а не диапазон текста; формат отображения выбирает потребитель.

`InternalLink(target_id)` назначается текстовому фрагменту через `set_internal_link(run, link)`. `get_internal_link(run)` читает роль, `set_internal_link(run, None)` снимает её. Назначение не меняет текст и стиль. Одновременные `TextRun.link` и явная внутренняя роль отклоняются: сначала удалите прежнюю ссылку явно. Строка `TextRun.link="#chapter"` остаётся прежней свободной строкой; библиотека не интерпретирует её как новую роль.

ID — непустая UTF-8-строка, локальная для документа. Это не URL или путь: пробелы, `/` и `#` не запускают специальный разбор. Пустые строки, нестроковые значения и непарные Unicode-суррогаты отклоняются. Пространство ID якорей независимо от ресурсов, стилей и списков.

## Проверка и поиск

`iter_anchors(root)` и `iter_internal_links(root)` возвращают живые `NodeLocation` в общем порядке обхода, включая вложенные таблицы и все семь коллекций секции. Обход поддерева не проверяет цели за его пределами. Действуют общие `DocumentLimits`.

`resolve_anchor(document, id)` проверяет весь документ и возвращает точное положение либо `None`, если искомого якоря нет. Некорректный документ даёт `ValueError`; превышение бюджета — `ArtifactLimitError`. Внешние источники ресурсов не открываются. После структурного изменения найдите положение заново.

Валидация модели, чтение/запись JSON и `check_document` проверяют единственность ID и наличие каждой цели. Два вхождения одного общего объекта с якорем тоже неоднозначны и дают `semantic.anchor.duplicate`. Отсутствующая цель даёт `semantic.anchor.missing`, конфликт с `TextRun.link` — `semantic.link.conflict`. Ошибка содержит путь поля; измерение дубля — первое положение, отсутствующей цели — ID. Порядок объявления не важен. Ссылка на себя и циклы между существующими целями допустимы: содержимое цели не разворачивается рекурсивно.

Setters проверяют локальные данные до записи, сохраняют неизвестные поля распознанного расширения на независимой копии и не трогают другие свойства. Уникальность и существование целей проверяются на уровне документа: можно сначала создать связанные элементы, затем проверить собранную модель. Удаление якоря с оставшимися ссылками делает модель некорректной; перенаправляйте или удаляйте ссылки явно.

## Композиция и извлечение

`merge_documents` по умолчанию отклоняет конфликты якорей. `conflicts="rename"` выбирает свободные ID с учётом имён всех входов, переписывает определения и явные внутренние ссылки и возвращает `DocumentIdMap.anchors`. Общие узлы и bags переписываются по снимку исходных ID. Непрозрачные расширения и строки `TextRun.link` не переписываются. Прежние позиционные аргументы карты сохранены, новая карта имеет независимое пустое значение по умолчанию.

`extract_document` сохраняет цели ссылок. Если фрагмент уже содержит цель, дополнительный контент не добавляется. Иначе включается целиком исходная секция цели, включая колонтитулы и зависимости; её ссылки обрабатываются транзитивно. Если недостающая цель находится в секции выбранного фрагмента, эта секция расширяется до полной исходной. Результат может содержать больше контента, чем выбранное поддерево. Секции располагаются в исходном порядке, перекрывающиеся оболочки не дублируются. Политика непрозрачного пакета остаётся явной, стили и ресурсы собираются после расширения секций, результат независим от исходника.

## Измерение изменений

Инспекция добавляет счётчики `anchors` и `internal_links`, а в `metadata.semantic_references` — инвентарь `opendoc.references` v1: ID, положения и типы носителей якорей, текст и SHA-256 каждого вхождения ссылки, ID и положение её цели. Снимок не входит в JSON документа.

Сравнение возвращает `object_diff.references`. Якоря сопоставляются по ID, ссылки — по текстовому отпечатку, затем по положению как эвристике. Кратность одинаковых ссылок сохраняется, неоднозначность пары отмечается `ambiguous`. Потеря известного якоря даёт `LOSS/anchor-loss`, удаление ссылки — `LOSS/internal-link-loss`. Перемещение якоря, изменение его типа, смена цели, текста или положения сопоставленной ссылки дают предупреждения `anchor-change` или `internal-link-change`. Изменение только текста цели относится к обычному сравнению содержимого, а не к смене ID.

Диагностика в памяти содержит снимки обеих сторон измерения. `QualityPolicy` может запрещать эти потери; объектная политика сама по себе проверяет инвентарь объектов. Старый, неподдержанный или повреждённый инвентарь ссылок означает `available=False` и `None` для счётчиков, а не ноль потерь или доказанную сохранность.

## Решение о схеме

Якорь хранится в `properties["opendoc.anchor"]` как `{"format": "opendoc.anchor", "version": 1, "id": "chapter"}`; ссылка в свойствах `TextRun` — как `{"format": "opendoc.internal-link", "version": 1, "target_id": "chapter"}`. Роли распознаются только на перечисленных носителях. Неподдержанная версия явно объявленного расширения отклоняется, неизвестные дополнительные поля сохраняются. Непромаркированное значение остаётся непрозрачным; setter отказывается перезаписывать или удалять занятый им ключ.

Контракт входит в API библиотеки. Типы элементов, старые сигнатуры и значения по умолчанию не изменены. JSON документа записывается как v2 и читается как v1/v2, схема bags остаётся v1: прежний reader сохраняет неизвестные свойства, но не проверяет новую семантику. Прикладные bookmarks и fragment-строки автоматически не мигрируют. Независимые входы v1/v2 и сохранённый API проверяются регрессионными тестами.

Исполняемый пример: [examples/references.py](../../examples/references.py).

Якоря и ссылки также доступны в [телах сносок](footnotes.md). При извлечении недостающий якорь внутри сноски включает её определение целиком; цели в основном содержимом включают секцию. Ссылка и ссылка на сноску не могут занимать один `TextRun` одновременно.
