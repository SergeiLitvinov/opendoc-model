# Структурная валидация

`DocumentModel.validate()` возвращает список ошибок с путями вида `sections[0].blocks[0].rows[0].cells[0].row_span`. Пустой список означает, что модель соответствует структурному контракту OpenDoc Model. Проверка не меняет документ и не открывает внешние источники ресурсов.

```python
from opendoc_model import DocumentModel, Image, Section, document_to_json, inspect_document_model

document = DocumentModel(sections=[Section(blocks=[Image("missing")])])
errors = document.validate()
assert errors == ["sections[0].blocks[0]: unknown resource 'missing'"]
inspection = inspect_document_model(document)
assert not inspection.valid
assert inspection.metrics == {}
try:
    document_to_json(document)
except ValueError as error:
    assert "unknown resource" in str(error)
else:
    raise AssertionError("Invalid structure must not be saved")
```

## Общие правила

Ручное создание модели, чтение собственного JSON v1/v2 и запись используют одинаковые семантические проверки. Чтение дополнительно проверяет форму JSON до конструирования объектов. Запись отклоняет повреждённую модель с `ValueError` до замены файла. Диагностика JSON может содержать дополнительный префикс `$.document`; точный текст сообщений не является машинным кодом ошибки.

Валидация проверяет:

- Типы секций, страниц, блоков и inline. Блоки — абзац, таблица, изображение или формула; inline — текст, изображение или формула. Таблица внутри абзаца недопустима. Вложенные таблицы в ячейках допустимы. Все семь коллекций секции проверяются по одним правилам.
- Ссылки абзацев и таблиц на стили, `base_style_id` именованных и inline-стилей, отсутствие циклов наследования. Неизвестные стили отклоняются.
- Основной ресурс изображения, его `fallback_resource_id`, visual surrogate каждого элемента и `TextRun.properties.resource_id`. Ключ ресурса совпадает с его `id`. Идентификаторы ресурсов/стилей непустые; ресурс содержит встроенные байты или внешний `source`. Пустые встроенные байты допустимы.
- Положительные целочисленные `row_span` и `column_span`; `bool` не считается числом span. Проверка не выводит размеры сетки из span и не требует прямоугольности таблицы.
- Конечные координаты и угол поворота, неотрицательные размеры элементов. Ширина/высота страницы и размер шрифта положительны; поля страницы неотрицательны и оставляют область содержимого.
- Каждая доля обрезки изображения находится в диапазоне 0–1. Сумма противоположных сторон строго меньше 1.
- Enum режима, вида ресурса и формата формулы, текстовые/булевы поля, непустой исходник формулы, происхождение и историю преобразований. Fidelity surrogate — конечное число 0–1 или `None`.
- Допустимые JSON-значения расширяемых свойств и метаданных. Неизвестные прикладные поля сохраняются; OpenDoc Model не назначает им семантику самостоятельно.

Нарушения типов изменяемых контейнеров дают диагностику, а не случайную ошибку при обходе. Циклы отклоняются до рекурсивного чтения содержимого. Повторное вхождение одного поддерева допустимо и проверяется в каждом месте.

## Непрозрачный пакет

`PackageGraph.validate()` проверяет пакет самостоятельно; `DocumentModel.validate()` включает ту же проверку с префиксом `package`.

Имя части — абсолютный путь с `/`, без пустых сегментов, `.` и `..`. Ключ `parts` совпадает с `PackagePart.name`, содержимое — байты. Корень может быть `/` или абсолютным нормализованным логическим якорем; наличие отдельной части для якоря необязательно.

Связь имеет непустые `id`, `relationship_type` и `target`; пара `(source, id)` уникальна. Источник — часть, корневой якорь или контейнер `/`. Внутренняя цель — нормализованное имя существующей части. Внешняя цель остаётся непрозрачной строкой и не загружается. Валидация не интерпретирует содержимое частей и не обращается к адаптерам офисных форматов.

## Инспекция и бюджеты

`inspect_document_model()` сначала проверяет структуру. При ошибках он возвращает `valid=False` и issues категории `model-validation` с отдельным `location`. Метрики и инвентарь остаются неизвестными, а не изображают измеренный пустой документ. Неизвестный инвентарь не считается доказанной потерей объектов при сравнении.

Для допустимой структуры инспекция считает метрики и добавляет предупреждения о выходе элемента за страницу, отсутствии альтернативного текста изображения, переносимого fallback формулы и неиспользуемых ресурсах. Они не запрещают JSON-сохранение. Структурные проверки не подтверждают внешний вид, доступность внешнего файла или редактируемость документа в приложении.

`validate()`, `PackageGraph.validate()` и `inspect_document_model()` принимают необязательный `limits=DocumentLimits(...)`. Превышение [бюджета](limits.md) вызывает `ArtifactLimitError` и не превращается в успешный или частично измеренный отчёт. При недостаточном бюджете сбор всех ошибок не обещается.
