# Исполняемые сценарии

Каждый файл в `examples/` — самостоятельный сценарий публичного API с
проверкой результата и ожидаемого отказа, когда он относится к сценарию.
`uv run python -m tools.docs check` запускает все эти файлы перед строгой
сборкой сайта. Они используют временные каталоги или `.opendoc/`, не требуют
редактора, сервера приложения или пользовательских документов.

## Вложенная структура и колонтитулы

`Section` хранит `blocks` и шесть отдельных коллекций: `headers`,
`first_page_headers`, `even_page_headers`, `footers`, `first_page_footers`,
`even_page_footers`. Это содержимое модели; оно не вычисляет число страниц
или размещение в приложении. В каждой коллекции допустимы поддержанные блоки,
включая таблицы с таблицами внутри ячеек.

`section_content.py` создаёт двухуровневую таблицу в основном содержимом
и отдельные абзацы во всех колонтитулах. Итератор `iter_elements(document,
Paragraph)` даёт семь точных путей в документированном порядке: три верхних
колонтитула, основной текст, три нижних. После JSON-восстановления пути и
содержимое совпадают. Правка фрагментов копии не затрагивает оригинал;
нулевой `column_span` даёт структурную ошибку с расположением.

## Политики решают разные вопросы

В `quality.py` происхождение сохраняет идентичность абзаца/фрагмента после
изменения текста. Объектная политика подтверждает присутствие объекта,
а точная текстовая отклоняет изменение. Допуск одной правки слов принимает
замену одного слова; он не меняет решение точной политики. Изменение bold
считается отдельно по непробельным символам; бюджет LOSS считает уже сообщённые
потери. Ни одна из этих проверок не измеряет внешний вид или редактируемость.

`optional_math.py` исполняется и без `math`: LaTeX доступен, XML-проверка возвращает
неизвестное измерение и строгая политика отказывает. С extra `math` поддержанные
деревья измеряются, неподдержанный XML остаётся неизвестным. CI дополнительно
запускает этот файл Python обеих изолированных установок wheel.

Подробные границы находятся в [правилах качества](quality.md),
[формулах](formulas.md), [обходе](traversal.md) и [JSON](json.md).
Справочник API и навигация по коду генерируются из исходников; наличие прямого
импорта в тесте не является утверждением о покрытии поведения.
