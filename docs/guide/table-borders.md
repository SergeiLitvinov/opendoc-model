# Границы таблиц и ячеек

С версии 0.8.0 библиотека хранит и проверяет явные декларации границ. Это
расширение модели документа: оно не добавляет чтение офисных форматов,
компоновку, рисование или разрешение конфликтов соседних границ.
Полный исполняемый пример — [table_borders.py](../../examples/table_borders.py).

## Типы и стороны

`BorderSet(sides, extra={})` содержит словарь сторон с записями `Border`.
Названия относятся к исходной системе координат таблицы/ячейки до поворота;
они не переключаются автоматически по направлению текста.

| Владелец | Допустимые стороны |
| --- | --- |
| `Table` | `top`, `right`, `bottom`, `left`, `inside-horizontal`, `inside-vertical` |
| `TableCell` | `top`, `right`, `bottom`, `left`, `diagonal-down`, `diagonal-up` |

`diagonal-down` идёт из верхнего левого угла в нижний правый (↘),
`diagonal-up` — из нижнего левого в верхний правый (↗).
Внутренние границы — декларации для внутренних разделителей таблицы.
Модель не вычисляет их сегменты при span и не выбирает победителя между
границей таблицы и прямой границей ячейки.

| Поле `Border` | Значение |
| --- | --- |
| `kind` | `line` (по умолчанию), `none` или `nil` |
| `style` | `solid`, `dashed`, `dotted`, `double`, `dash-dot`, `dash-dot-dot` или `None` |
| `color` | Существующий `ColorValue` или `None` |
| `width_pt`, `offset_pt` | Конечные неотрицательные числа в пунктах (1 pt = 1/72 дюйма) или `None` |
| `extra` | Независимые неизвестные JSON-поля записи |

`None` у атрибута означает неизвестное значение: оно не заменяется чёрным
цветом, сплошной линией или типовой толщиной. Нулевая толщина допустима и
сохраняется как число; её отображение модель не определяет. `offset_pt` —
заявленное расстояние от края владельца, без вычисления геометрии/направления
смещения. Для двойной линии ширина — заявленная общая толщина; разделение
на штрихи и промежутки не рассчитывается. Неподдержанный нативный стиль можно
сохранить в `extra`, оставив `style=None`; это не обещает его отображение.

## Отсутствие, отключение и наследование

Отсутствующая сторона означает отсутствие прямой декларации. `Border("none")`
явно отключает линию; `Border("nil")` хранит отдельное явное состояние сброса
к отсутствию линии. Оба состояния запрещают наследовать линию для этой стороны,
различаются в JSON и не допускают известных атрибутов линии. Отображение
нативных `none`/`nil` в эти состояния определяет вызывающий код.

`resolve_borders(node, inherited=BorderSet(...), limits=None)` принимает только
явно переданные декларации того же типа владельца. Прямая сторона заменяет
унаследованную **целиком**, включая её неизвестные атрибуты. Неуказанные прямые
стороны берутся из `inherited`; без него они остаются неизвестными. Результат
независим от переданных словарей и не записывается в документ. Функция не ищет
нативные стили и не выводит границы ячейки из границ таблицы.

```python
from opendoc_model import Border, BorderSet, TableCell, resolve_borders, set_border

cell = TableCell([])
fallback = BorderSet({"top": Border(style="solid", width_pt=0.75)})
set_border(cell, "top", Border("none"))
assert resolve_borders(cell, inherited=fallback).sides["top"].kind == "none"
set_border(cell, "top", None)
assert resolve_borders(cell, inherited=fallback).sides["top"].width_pt == 0.75
assert not resolve_borders(cell).sides
```

`get_borders(node, limits=None)` возвращает независимый `BorderSet` или `None`.
`set_borders(node, value, limits=None)` заменяет прямые стороны; `None` удаляет
всю известную декларацию. `set_border(node, side, value, limits=None)` меняет
одну сторону, сохраняя остальные и верхние неизвестные поля. `None` удаляет
эту прямую сторону, позволяя явно переданному наследованию снова применяться;
`none`/`nil` нужны для запрета такого наследования. Прежняя прямая декларация
после удаления не восстанавливается.

Свежая `Border` заменяет сторону целиком. Для правки с сохранением её `extra`
используйте `dataclasses.replace(record.sides[side], width_pt=...)`. Неизвестные
верхние поля предыдущего `BorderSet` сохраняются при замене, новые одноимённые
значения имеют приоритет. Удаление всей декларации удаляет и её неизвестные поля.

## JSON, валидация и сравнение

Схема границ имеет собственную версию 1. Ключ таблицы —
`TABLE_BORDERS_PROPERTY = "opendoc.table-borders"`, ключ ячейки —
`CELL_BORDERS_PROPERTY = "opendoc.cell-borders"`. Конверт лежит в `properties`:

```json
{"format":"opendoc.table-borders","version":1,"sides":{"top":{"kind":"line","style":"solid","color":null,"width_pt":0.75,"offset_pt":null}}}
```

JSON документа v1/v2, bags v1, прежние конструкторы и `width_twips` сохранены.
Старые документы не получают выдуманных границ; старый reader сохраняет новые
ключи непрозрачно. Новые обязательные зависимости не добавлены.

Чтение/запись JSON, `check_document` и структурные правки проверяют владельца,
стороны, типы, цвета, значения, версию и `DocumentLimits`. Ошибки дают расположение
и `semantic.border.invalid`; превышение бюджета — `ArtifactLimitError`.
Отказ setter и структурной правки атомарен. Boolean не считается числом или
версией. Неизвестные поля сохраняются на уровнях набора и отдельной стороны;
поля `extra`, `format`/`version` и имена известных полей нельзя затенять.
Непомеченное значение занятого ключа, включая `null`, остаётся непрозрачным:
getter возвращает `None`, setter отказывается его перезаписать или удалить.
Неизвестная версия помеченной схемы отклоняется.

Инспекция содержит `table_borders`: `table` с декларацией таблицы (или `null`)
и `cells` со словарём объявленных ячеек. Ключ `"row:column"` задаёт нулевые
индексы строки и ячейки в `Table.rows`/`TableRow.cells`, без расчёта логических
координат span. Ячейки без декларации в словарь не включаются: изменение размера
таблицы само по себе не выдумывает изменение её границ.
`compare_documents` сообщает `table-border-loss` при удалении стороны/известного
значения, утрате неизвестных полей или замене линии на `none`/`nil`;
`table-border-change` — при прочих изменениях. Диагностика включает расположение
таблицы и исходный/итоговый снимки. Старые снимки без этого поля не дают ложной
потери. Сравнение оценивает декларации, не внешний вид; явно переданное
наследование вне документа автоматически не сравнивается.

Clone, merge и extract сохраняют декларации как часть свойств. Собственные
[тесты](../../tests/test_table_borders.py) проверяют стороны, два JSON-цикла,
наследование, правки/удаление, неизвестные поля, старый JSON, композицию,
диагностику и отказы. Пример запускается документацией и установленным wheel
без сторонних зависимостей.
