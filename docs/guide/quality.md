# Сравнение и политики качества

Инспекция и сравнение работают в памяти: `before = inspect_document_model(source)`, `after = inspect_document_model(target)`, `comparison = compare_inspections(before, after)`. `comparison.to_dict()` и `ConversionReport.to_dict()` дают JSON-совместимые результаты. Политики записывают решения в отчёт, а потребитель решает, что делать с результатом.

```python
from pathlib import Path
from opendoc_model import (
    ConversionReport,
    DocumentModel,
    ObjectLossPolicy,
    Paragraph,
    Section,
    TextPreservationPolicy,
    TextRun,
    compare_inspections,
    inspect_document_model,
)

source = DocumentModel(sections=[Section(blocks=[Paragraph([TextRun("Сохранённый текст")])])])
target = DocumentModel(sections=[Section(blocks=[Paragraph([TextRun("Сохранённый текст")])])])
comparison = compare_inspections(inspect_document_model(source), inspect_document_model(target))
report = ConversionReport(Path("document.json"))
assert ObjectLossPolicy().evaluate(report, comparison)
assert TextPreservationPolicy().evaluate(report, comparison)
assert report.success
```

Текущий `ConversionReport` требует `output_path` как метку назначения: вызов политики не записывает туда файл. Возвращаемый `bool` относится к конкретной политике; `report.success` учитывает все ошибки отчёта. Успех одной проверки не отменяет уже зарегистрированную ошибку другой.

## Измерение и неизвестность

Инспекция допустимой модели устанавливает версии полного инвентаря объектов и структурных метрик. Пустой документ имеет измеренные нулевые значения и проходит строгие проверки. Повреждённая модель не получает измерений. Отдельный `DocumentInspection` с отсутствующими метриками остаётся частичным: неизвестное значение — `None`, а не ноль.

В `comparison.retention` для неизвестной стороны `delta` и `ratio` равны `None`. Сравнение не объявляет уменьшение без измерений обеих сторон. Геометрия без сопоставимых страниц имеет `available=False` и неизвестные ошибки размеров/полей.

Ресурсы и части пакета сопоставляются по хешам с учётом количества одинаковых вхождений. Если инвентарь или какой-либо хеш отсутствует, полнота сохранности имеет `available=False`, отношения равны `None`, списки доказанных потерь/добавлений остаются пустыми. Известные точные совпадения по-прежнему учитываются; ресурсы без хеша перечислены в `unmeasured_source_resources`/`unmeasured_target_resources`. Внешний ресурс не получает хеш только по имени или факту существования файла.

Шрифты сравниваются по числу фрагментов с нормализованными названиями: убирается префикс поднабора, приводятся известные aliases. Возможные замены — предположения по количеству фрагментов. При неизвестном полном инвентаре отсутствующие семейства и сохранность не объявляются измеренными.

## Контракты политик

С версии 0.10.0 flow-проверка также принимает [измеренный текстовый профиль](text-flow-profile.md)
с собственной подтверждённой областью. Это не требует объявления полного
модельного инвентаря и не разрешает остальные независимые политики.

| Политика | Что проверяет | Допуск и недоступность |
|---|---|---|
| `QualityPolicy` | Количество зарегистрированных событий `LOSS` | `max_loss_issues`; не измеряет объекты и не подтверждает полноту инспекции |
| `ObjectLossPolicy` | Несопоставленные рекурсивные объекты | `max_lost_objects`; строгая проверка отклоняет неизвестный инвентарь, эвристические и неоднозначные совпадения |
| `TextPreservationPolicy(mode="paragraphs")` | Точный текст непустых исходных абзацев с учётом дубликатов | Перестановка и дополнительные абзацы допустимы; разделение/объединение меняет отпечаток |
| `TextPreservationPolicy(mode="flow")` | Полную последовательность текста после нормализации пробелов и границ абзацев | Порядок слов и все остальные символы сохраняются; дополнительные слова меняют последовательность |
| `TextPreservationPolicy(mode="flow", max_text_edits=N)` | Расстояние Левенштейна между словами | Вставка, удаление и замена стоят 1; перестановка не имеет отдельной скидки |
| `FormulaLossPolicy` | Несовпавшие или удалённые исходные формулы с учётом дубликатов | `max_changed_formulas`; добавления допустимы. LaTeX сравнивается точно, XML требует доступного поддержанного отпечатка |
| `EmphasisLossPolicy` | Число непробельных символов с изменением bold/italic | `max_changed_emphasis`; изменение обоих признаков считается один раз. Изменённый текст даёт недоступность сопоставления |

Все числовые бюджеты — неотрицательные целые числа; `bool` недопустим. Равенство бюджету принимается, превышение отклоняется. Невозможность измерения не проходит строгий допуск даже с большим бюджетом. Каждое решение содержит `accepted`, а измерительные политики также `verified` и `reason` (`accepted`, `budget-exceeded`, `unavailable` или специализированную причину).

Сопоставление объектов сначала использует происхождение, затем содержимое; расположение — эвристика. Вхождения с одинаковым содержимым не сворачиваются в одно. Идентичность объекта позволяет доказать его присутствие после изменения, но не доказывает сохранность текста: для неё нужна отдельная политика. Геометрия объекта, изменение текста и отсутствие объекта сообщаются отдельно.

Текстовые политики учитывают `TextRun.text`; исходники формул и alt-текст изображений исключены. Bold/italic сейчас измеряются по значениям фрагментов, а не по результату рендеринга. Проверки не измеряют внешний вид, качество шрифтов или редактируемость в приложении.

## Точность и вычислительные пределы

Геометрия страниц сопоставляется по индексу. Допуск размера и полей — 0,5 пункта включительно; решение принимается до округления показателей для отчёта. Добавленная страница является предупреждением, исчезнувшая — потерей. Геометрия объектов в инвентаре округлена до 0,001 пункта.

Поток текста сохраняет точный отпечаток независимо от длины; список отпечатков слов ограничен 10 000 словами. При превышении этого числа неизменённый поток всё ещё проверяется точно, а расстояние изменённого потока недоступно. Расчёт расстояния имеет бюджет 2 000 000 ячеек. Доказанное превышение возвращает нижнюю границу `N+1`, а вычислительный отказ оставляет её неизвестной. Нижняя граница никогда не выдаётся за точное число правок.

Представление выделений ограничено 10 000 чередующимися участками. Соседние участки с одинаковым bold/italic объединяются. При превышении список участков становится недоступным, строгий допуск выделений отклоняет результат. Сами отпечатки и число символов остаются доступны.

Проверки границ, неизвестности и всех политик находятся в `tests/test_quality_contracts.py`; перестановки, удаление вхождений и конфликты происхождения — в `tests/test_object_matching.py`.
