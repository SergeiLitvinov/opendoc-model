# Аудиты OpenDoc Model

## C-LIST-02: границы и продолжение пункта — 20 октября 2026

Аудит существующего API подтвердил пробел: `ListItem` описывал отдельный абзац,
а plain paragraph не отличал продолжение от абзаца вне списка. Расширен прежний
тип, без нового AST: `continuation_of` / `parent_id` ссылаются на Anchor первичного
абзаца. Счётчик увеличивается на пункт; продолжения не сбрасывают вложенные уровни.
Пустой родитель остаётся явным пустым абзацем. Удаление используемого первого
абзаца/родителя структурной операцией откатывается; перенос роли не угадывается.

Независимый минимальный документ содержит First., Continuation., Outside.,
пустого родителя, дочерний пункт и его продолжение. Проверяются два JSON-цикла,
clone, remap при конфликтующих якорях и списках, замыкание extract, правка,
удаление/явное повышение продолжения, dangling, неверные цели, циклы и лимиты.
Неизвестные поля непрозрачны; прежние свойства не восстанавливают снятые связи.
Старая роль версии 1 и её JSON не меняются; новые связи требуют версии расширения 2,
чтобы прежний читатель отказал, а не пронумеровал продолжение как новый пункт.
Версия документа и набор зависимостей прежние. Нативные парсеры, маркеры,
пользовательские метки и проверка отображения в библиотеку не переносятся.

Приёмка: 1630 passed, 3 платформенных пропуска, 27 новых регрессий. Ruff,
strict mypy 49 модулей, все примеры, актуальная справка и строгая сборка сайта
прошли. Лицензионные сведения 29 locked/build пакетов проверены. Wheel/sdist и
wheel из sdist имеют одинаковое содержимое; чистая установка без зависимостей
прошла runtime и статическую проверку потребителя, обнаружены все 13 намеренных
ошибок типов. Официальный wheel 0.16.0 сверён по GitHub SHA256: прежний JSON
списка точно сохраняется в двух циклах, новая версия роли явно отклоняется.
Сохранён прежний точный порог max_nodes=4 для минимального JSON-документа.

## C-GRAPHICS-02: пространство композиции группы — 18 октября 2026

Аудит подтвердил пробел: ColorSpace описывает отдельные значения sRGB/CMYK,
а строка ColorValue.icc_profile не является проверяемой ресурсной ссылкой.
В 0.16.0 существующий GroupCompositing дополнен GroupColorSpace: rgb/gray/cmyk,
явное srgb, профильное icc и unknown. Отсутствие не подменяется пространством
Paint/родителя или native extra. Новое поле по умолчанию не меняет прежний JSON
и бюджет обхода; интеграционный конверт и версия scopes сохранены.

Собственные непрозрачные профили проверяют различия пространств, два JSON-цикла,
правку/удаление группы и occurrence, независимость, clone/merge/extract и ресурсные
операции с точным remap. Dangling/wrong-kind, неподдержанные значения, ICC без
профиля и конфликт sRGB/profile отклоняются атомарно. Новая INFO диагностика
делает неизвестность пространства явной. Заданный большой бюджет и embedded=0
передаются через внутреннюю проверку; имена native CS не интерпретируются.
ICC байты, число каналов, преобразования и реальные цвета пересечения не проверялись:
это остаётся за границей модельного контракта и не объявляется выполненным.

Локальная приёмка: 1603 passed, 3 платформенных пропуска, 21 новая регрессия.
Ruff, strict mypy 49 модулей, справочник, все примеры и строгий сайт прошли.
Лицензии 29 locked/build пакетов прежние. Wheel/sdist и пересобранный wheel
совпадают, чистый пакет без зависимостей и типизированный потребитель проверены;
12 намеренных статических ошибок обнаружены. Официальный wheel 0.15.0 сверён
по GitHub SHA256: новые пространства, профильные ссылки, unknown/отсутствие и
extra сохранились в двух JSON-циклах. Это транспорт, а не понимание цветиметрии
или remap новых ссылок старой версией.

## C-GRAPHICS-01: смешанные clip/group scopes — 18 октября 2026

Проверка подтвердила пробел VectorScene: прежние shapes были только векторными,
а group.opacity не описывала isolation/knockout/blend для mixed paint occurrences.
В 0.15.0 развивается этот же scene graph: VectorClip, SceneOccurrence,
GroupCompositing, scope_version=1 и атомарные get/set/remove операции. Сохранены
позиционные сигнатуры и JSON старой сцены без новых полей; новый маркер не
снимается удалением параметров и не восстанавливает legacy opacity/clip.

Собственный конечный корпус проверяет декларации двух пересекающихся путей
с общей .5 opacity и отдельной .5 у ребёнка, clip cubic/evenodd с отверстием,
текст без удаления скрытых символов, Image/Table и два независимых occurrences
общего якоря. Два JSON-цикла, правка/удаление, unknown INFO, атомарные ошибки,
композиция, ресурсные/якорные ссылки и выбранный бюджет покрыты. Инспекция
не помечает ресурс, используемый integration-ссылкой, как неиспользуемый.

Найден общий дефект _acyclic: дочерние группы, уже посещённые раньше родителя,
обходили лимит глубины. Итеративная проверка высоты подграфа теперь не зависит
от порядка записей; циклы и бюджет сохраняются. Нативных файловых циклов,
подсчёта цвета пересечения и проверки отображения не выполнялось — это граница
данного модельного аудита, а не заявление об их готовности.

Локальная приёмка: 1582 passed, 3 платформенных пропуска; 20 новых регрессий.
Ruff, strict mypy 49 модулей, справочник, примеры и строгая сборка сайта прошли.
29 locked/build пакетов имеют прежние лицензии. Wheel/sdist и пересобранный
wheel совпадают; чистая установка без зависимостей и типизированный потребитель
проверены, 12 намеренных ошибок обнаружены. Официальный wheel 0.14.0 сверён

подтвердила сохранность scopes и исходника. Новому профилю требуется 0.15.0.

## C-FONT-01: ссылки на программы шрифтов — 18 октября 2026

В 0.14.0 реализован общий FontReference на существующий FONT resource через
типизированное свойство TextStyle. Собственные разные opaque payload с одним
семейством остаются разными; face_index None не заменяется нулём. Проверены
два JSON-цикла, модельное наследование, правки и удаление, независимые значения,
clone/extract/merge с конфликтами ID и повторным владельцем. Учитываются
именованные стили, ресурсные удаления/замены и замыкание ресурсов их цепочки.
Неверные ID/kind/index/владелец/версия дают адресный отказ; увеличенный бюджет
передаётся getter/setter, инспекции и JSON, setter атомарен.

Исправлен контекст проверки inline override в resolve_style: он теперь включает
ресурсы документа и не теряет корректные FONT-ссылки. Добавлен отдельный обход
прямых font bindings, включая dictionary стилей. JSON без ссылок, read1/2/write2,
старые конструкторы и зависимости сохранены. Нативное извлечение, проверка
шрифтовых программ/прав, встраивание и отображение этим аудитом не выполняются.

Локальная приёмка: 1562 passed, 3 платформенных пропуска, 16 новых регрессий;
Ruff, strict mypy 48 модулей, все примеры и строгая документация прошли.
Лицензии 29 locked/build пакетов прежние. Wheel/sdist и пересобранный wheel
совпадают, чистый пакет без зависимостей и типизированный потребитель приняты;
12 намеренных ошибок типов обнаружены. Официальный wheel 0.13.0 проверен по

независимость, расширения, ошибочные версии, лимиты и атомарность закреплены

[Руководство](../guide/line-spacing.md) и [контракт](model-contract.md) описывают
точные единицы, миграцию и границы. Реальные нативные документы не использовались:
аудит модели не подтверждает расчёт высоты, отображение или нативный экспорт.

Существующие страницы, PageGeometry, Box, векторные линии, provenance,

двухстраничного примера. Нового типа не требуется. 11 новых тестов проверяют

аудит не выполняет реальный PDF-цикл и не принимает его нативный вывод.
Сохранение 2 страниц собственного примера не доказывает исправление прежнего
размножения страниц адаптером. Произвольные clip/group, visual surrogate,

## Цвет: явный auto, отсутствие и наследование — 11 октября 2026

Проверены существующие `TextStyle.color/background`, `ColorValue`,
`resolve_style` и `effective_text_style`. Строка auto сохраняет явную
декларацию, None/отсутствующее JSON-поле разрешают наследование; неизвестное
значение не становится чёрным. Новый тип и новая схема не требуются.
Модель не вычисляет нативный RGB auto, темы или каскад приложения.

Найден пробел сравнения: прямой auto → None/унаследованный цвет не давал
цветовой диагностики. В 0.11.2 добавлены снимки прямых и разрешённых модельных
деклараций использованного текста/стиля абзаца, расположенные change/loss и
source/target. Интервалы объединяются независимо от разбиения runs.
Сравниваются только абзацы с одинаковым известным текстовым хешем; старый
inventory, повреждённый снимок и поддерево без контекста named styles остаются
неизвестными. Неиспользованные стили и нативные properties не интерпретируются.
`color_to_css("auto")` исправлен: возвращает None вместо невалидного CSS.

26 собственных тестов закрепляют auto/None/пустой legacy token/RGB/ColorValue,
цвет и фон, named/inline inheritance, явную правку и удаление, повторное
наследование того же auto, два JSON-цикла v1/v2, split runs, изменения текста,
копирование/merge/extract, неизвестный inventory и независимость документа.
Запись с 100001 неизвестным значением проходит JSON и сравнение с явным
max_nodes=200000. Документ read1/2/write2, ColorValue JSON, bags, integration
и конструкторы сохранены. Обязательных зависимостей и стороннего кода нет.
Руководство содержит [исполняемый пример](../../examples/text_colors.py),
проверяемый также установленным wheel без зависимостей.

Локальная приёмка: 1500 тестов, 3 платформенных пропуска, Ruff, strict mypy
47 модулей, строгая сборка документации, лицензии 29 зафиксированных пакетов,
wheel/sdist parity и чистая установка wheel с исполнением типизированного
потребителя и обнаружением 12 намеренных статических ошибок.

Внешнее свидетельство касалось потери явного автоматического цвета;
собственный аудит воспроизводит только модельный контракт на новых
синтетических документах. Реальные форматные циклы, цвет приложения и причина
оформления частного документа этим аудитом не подтверждены.

## Отступ таблицы и табуляция — 11 октября 2026

Аудит обнаружил пробел: ParagraphProperties хранит отступы абзаца, но строгого
контракта отступа таблицы и tab stops с выравниванием/заполнителем не было.
В 0.11.0 добавлены [минимальные декларации](../guide/spacing.md) в properties:
пункты, неизвестное/ноль, позиции, явное отсутствие заполнителя, подавление
позиции, замена или дополнение явно переданного fallback.
Нативное чтение/запись, единицы исходного формата, каскад стилей и компоновка
не входят в изменение.

Заключительная проверка уточнила обработку несловарного `extra` при правке
существующей записи: отказ происходит до слияния расширений, с ValueError и
без изменения документа. Исправление включено в 0.11.1; 3 дополнительных
сценария проверяют None, список и строку для всех трёх сеттеров.

70 собственных синтетических сценариев закрепляют отступ 30 pt и позицию
396 pt/right/line через два JSON-цикла, отрицательные значения, все alignment/
leader, правки и удаление, unknown extras, ошибочного владельца, bool/NaN/Infinity,
дубликаты, неизвестную версию, непрозрачные ключи и атомарный отказ.
Clone/merge/extract сохраняют независимые декларации. Сравнение даёт адрес,
source/target и change/loss; старый inventory без новых полей остаётся неизвестным.
Большая запись с 100001 неизвестным значением проходит getter/setter, валидацию,
JSON, clone и resolver при явном max_nodes=200000; стандартный лимит не повышен.

Официальный wheel 0.10.2 с проверенным SHA-256
`71d24384c54f0f30f45d36653a29cacdab977ec8fc58eca8f729c93d8b8854ba`
установлен отдельно без зависимостей: два его JSON-цикла сохраняют все новые
значения и поля при сравнении JSON, затем новый API восстанавливает их.
Это совместимость непрозрачных property declarations, а не понимание нового API

## Границы назначения

Расширенная модель хранит сведения о полях, комментариях, ревизиях, сценах,
диаграммах, доступности, медиа, книгах и математических деревьях. Это структуры
в памяти, JSON и проверки. Она не вычисляет поля/формулы, не исполняет actions,
не отрисовывает файлы и не включает редактор, сеть, OCR или внешние движки.
Сохранение исходных bytes или визуальной замены не приравнивается к сохранению
редактируемой семантики. Профили — конечные заявления потребителя, а не обещание
поддержки полного файлового стандарта.

## Приёмка выпуска

Локальная приёмка включает Ruff, форматирование, strict mypy, весь pytest,
