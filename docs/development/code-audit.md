# Аудит подготовки выпуска — 2026-10-03

Проверена самостоятельность библиотеки, публичная совместимость, документация,
дистрибутивы и автоматизация GitHub. Производственный пакет использует стандартную
библиотеку и лениво подключаемый `lxml` из extra `math`; обязательных внешних
зависимостей нет. Архитектурные тесты проверяют вложенные импорты и запрещают
зависимость от приложения-потребителя. Mypy проверяет все 35 модулей в строгом режиме.

Удалены устаревшие сборки и тестовые окружения. Документы перенесены в `docs/`,
в корне оставлен `README.md` и файлы настройки проекта. Выполненный TODO удалён,
его результаты сохранены в [завершённых возможностях](completed.md). Навигация,
ссылки и расположение лицензии в metadata/wheel/sdist обновлены. Ruff, pytest,
mypy и uv используют `.opendoc/`; pytest переиспользует один временный каталог.
[Команда очистки](../guide/release.md#чистое-рабочее-дерево) удаляет рабочие
артефакты без удаления исходников и окружения разработки.

Версия хранится только в `opendoc_model.__version__`. Выпуск увеличивает её по явному
выбору и сначала проверяет изменённое дерево на всех поддержанных версиях Python.
Тег и коммит отправляются атомарно. Release публикуется после загрузки wheel,
sdist и SHA-256. CI и выпуск используют общую матрицу проверок; Pages получает
готовый артефакт после успешных проверок. Actions закреплены по SHA, права записи
ограничены задачами выпуска/публикации; дополнительные токены не нужны.

Локальная проверка: 1079 тестов прошли, 3 проверки POSIX/символьных ссылок
пропущены на Windows. Lint и форматирование проходят. Все 17 примеров исполняются,
сайт строго собирается; локальные HTML-ссылки проверены с префиксом `/opendoc_model/`.
Прямая и повторная сборки из sdist имеют одинаковое содержимое wheel. Обе
установки проверены в пустых окружениях без сторонних зависимостей и checkout,
включая типизированный API и optional math; отдельное окружение с `lxml` проверяет
доступность XML. Workflows проверены actionlint. Результаты удалённых запусков
находятся в GitHub Actions; локальный прогон не подменяет их статус.

Правила последующих изменений находятся в [стандартах](CODING_STANDARDS.md),
процесс автоматического выпуска — в [руководстве](../guide/release.md).
